Mirage Centers is a generative audiovisual record label founded by William Jourdain, the Canadian artist working under the moniker of Automatisme (Mille Plateaux, Constellation). Each release lives as its own low-tech, frugal, and generative web page: one audiovisual configuration is selected daily from a limited set, building gradients pieces, and making available the blueprint of a sustainable listening environment.

The file compression methods used reduce file size by around 90%, minimizing the energy required to run each release ecosystem. You also decide what loads. Pressing play is the activation, nothing before.

Shadow architecture: no streams until you choose, unlike most of the web, which fetches everything by default without asking.

EcoIndex score: 95/100 - Grade A. View detailed report.

One configuration per day. No feed. No catalogue. Limited resources. Deliberate playback. Every Mirage Centers release enters sleep mode at night. Why should the internet be online 24/7?
